# 톡todo 모바일 테스트 앱

`webtoon-viewer` 저장소의 네이티브 Android/Gradle 및 GitHub Actions APK 빌드 방식을 재사용한 임시 테스트 프로젝트입니다.

앱 아이콘은 캘린더·마이크·완료 체크를 결합한 보라색 생산성 앱 아이콘이며, 홈의 음성 입력 버튼은 작은 화면에서도 캘린더가 빨리 보이도록 컴팩트한 66dp 높이로 구성했습니다.

## 포함된 기능

- Android 한국어 음성 인식 화면 호출
- `오늘`, `내일`, `모레`, 요일, `8월 25일` 날짜 분석
- `다음주`, `담주`, `차주`, `다다음주`, `오는 금요일` 등 한국어 주간 표현 정규화
- `오전 10시`, `오후 3시 30분`, `저녁`, `3시 반` 시간 분석
- `8월 27일~28일`, 월·연도 경계, 요일 범위와 `다음주 금토일` 기간 분석
- 시간 범위, N시간/N일 동안, 하루 종일, 반복 및 마감 일정 구조화
- 한글 숫자, 정정 발화와 필러 처리
- 오전·오후가 불분명하거나 날짜가 모호하면 저장 전 확인 창 표시
- `30분 전`, `1시간 전`, `1일 전` 알림 분석
- 일정 카드의 `알림` 버튼에서 일정 시간, 5·10·15·30분, 1·2·3·6·12시간,
  1·2·3·5일, 1·2·4주 전 알림을 스크롤 목록에서 복수 선택
- 선택한 시점마다 개별 알림을 예약하며 `모두 해제`로 해당 일정의 알림만 끄기
- 완료하지 않은 지난 일정은 다음 날부터 매일 오전 9시에 한 번의 묶음 알림으로 안내
- 묶음 알림에는 최대 5개 제목을 표시하고, 완료·삭제된 일정은 자동 제외
- 휴대폰 재부팅 후에도 오전 9시 알림 자동 재등록
- 음성 인식 완료 즉시 날짜·시간·알림 분석 및 자동 저장
- 상단 오른쪽 `메모` 버튼에서 선택 날짜별 메모 작성·조회·삭제
- “내일 거래처 전화하기 메모해줘”처럼 말하면 일정이 아닌 해당 날짜의 메모장에 자동 저장
- 메모 제목을 비워 두면 내용 첫 줄을 간결한 제목으로 자동 사용
- 음성에 `중요`, `긴급`, `최우선`, `반드시`가 포함되면 중요 일정으로 자동 표시
- 상세 카드 제목 앞의 작은 `☆/★` 버튼으로 중요 여부를 한 번에 변경
- 시간이 없는 일정은 오전 9시가 아닌 입력 당시의 현지 시각으로 저장
- 월간 캘린더의 하루 일정은 미완료(빨강)·완료(파랑) 개수로 표시
- 캘린더를 좌우로 드래그하거나 화살표를 눌러 이전·다음 달로 이동
- 캘린더 아래 `━` 전용 손잡이를 아래로 당기면 일정 제목을 펼쳐 보고, 위로 밀면 숫자 보기로 복귀
- 캘린더 본문의 세로 동작은 화면 스크롤에 사용하고 좌우 드래그만 이전·다음 달 이동으로 처리
- 펼친 제목은 한 줄 말줄임과 `+N개` 표시를 사용해 다른 날짜 칸을 침범하지 않음
- 연도 버튼에서 2000~2100년, 월 버튼에서 1~12월을 직접 선택해 즉시 이동
- 여러 날 일정은 숫자를 반복하지 않고 미완료는 연한 빨간 선, 완료는 연한 파란 선으로 기간 표시
- 중요 일정이 포함된 캘린더 숫자와 기간선은 진한색으로 강조
- 중요 일정은 제목 앞 별표로 표시하고 날짜 상세 및 검색 결과에서 먼저 표시
- 날짜 선택 시 상세 할 일 카드 표시
- 상세 카드의 `수정` 버튼에서 제목·상세 내용·시작일·종료일·시작 시간·종료 시간·하루 종일 여부 변경
- 수정한 날짜와 시간에 맞춰 개별 알림을 자동으로 다시 예약
- 상세 카드에서 완료·미완료 상태 전환 및 삭제
- 제목·원래 음성 문장·카테고리를 대상으로 하는 키워드 검색
- 검색 결과 선택 시 해당 날짜의 캘린더와 상세 일정으로 바로 이동
- 공문형 붙여넣기는 `제목·행사명·안건`을 우선 사용하고 반복 필드의 공통 업무어로 제목 자동 요약
- 기존에 길게 저장된 공문형 제목도 앱 실행 시 간결한 제목으로 한 번 자동 정리
- SharedPreferences 기반 기기 내 저장
- AlarmManager와 로컬 알림
- 기간 일정은 연결선으로, 반복 일정은 해당 날짜의 숫자로 표시

## 휴대폰 테스트

1. `tok-todo.apk`를 Android 8.0 이상 휴대폰에 설치합니다.
2. 처음 실행할 때 알림 권한을 허용합니다.
3. `음성으로 일정 추가`를 누릅니다.
4. “내일 오후 3시 치과 예약 30분 전에 알려줘”라고 말합니다.
5. 음성 인식이 끝나면 일정이 즉시 저장되는지 확인합니다.
6. 캘린더에서 해당 날짜의 빨간 미완료 숫자를 확인합니다.
7. 날짜를 누르고 상세 카드에서 완료로 바꾼 뒤 숫자가 파란색으로 이동하는지 확인합니다.
8. 미완료 일정을 남겨 두면 다음 날 오전 9시에 한 번의 요약 알림으로 표시되는지 확인합니다.
9. 제목 앞의 `☆`를 누르면 `★`로 바뀌고 캘린더 숫자가 진해지는지 확인합니다.
10. 카드 아래의 `완료 | 수정 | 알림 | 삭제` 중 `수정`을 눌러 제목과 날짜·시간을 변경합니다.
11. `알림`을 눌러 여러 시점을 선택해 저장합니다.

음성 인식은 휴대폰에 설치된 Google 또는 제조사 음성 인식 서비스를 사용합니다. 서비스가 없거나 네트워크 상태에 따라 동작하지 않으면 홈의 직접 입력란을 사용할 수 있습니다.

## GitHub Actions에서 임시 APK 만들기

프로젝트를 GitHub 저장소의 루트에 올린 다음 `Actions > Build 톡todo test APK > Run workflow`를 실행합니다. 완료 후 `tok-todo-apk` artifact를 내려받습니다. 테스트용 debug APK이므로 별도의 서명 secret이 필요하지 않습니다.

## 로컬 빌드

- Android Studio에서 폴더를 열고 JDK 17과 Android SDK 35를 선택합니다.
- `Build > Build APK(s)`를 실행합니다.
- Gradle이 PATH에 있으면 `build-apk.cmd`를 실행할 수도 있습니다.

로컬 APK 경로: `app/build/outputs/apk/debug/app-debug.apk`
